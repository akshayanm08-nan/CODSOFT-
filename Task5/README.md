Face Detection and Recognition

Project Overview

This project is an AI-based Face Detection and Recognition application developed using Python and OpenCV. The system detects human faces in images or live webcam video streams using a pre-trained Haar Cascade classifier.

Features

- Real-time face detection using webcam
- Face localization with bounding boxes
- Fast and efficient processing
- Easy to use and beginner-friendly

Technologies Used

- Python
- OpenCV
- NumPy

Installation

1. Clone the repository:
   
   git clone https://github.com/yourusername/CODSOFT.git

2. Install required libraries:
   
   pip install -r requirements.txt

3. Run the project:
   
   python face_detection.py

Output

The application opens the webcam and detects faces in real time. Detected faces are highlighted with a blue rectangle.
